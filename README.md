# BigData-ML

Assignment Overview 
This assignment applies big data analytics & machine learning using Apache Spark, split into 3 parts:
•	Part A: Exploration & visualisation of UK crime data (2023-2024) using Spark SQL and PySpark to discover regional and timely trends.
•	Part B: Machine learning on a Loan Prediction dataset to build & evaluate Logistic Regression, Random Forest, and Naive Bayes models for loan approval prediction.
•	Part C: Ethical reflection addressing privacy, fairness, accountability, and the social impact of big data and AI.
Datasets:
•	Crime Data: Records from Derbyshire, Leicestershire, and Nottinghamshire Police (2023–2024).
•	Loan Data: Applicant demographic & financial details for predicting loan approval outcomes.
